# BlueCity expansion feature traceability

Audit date: 2026-10-23. This is a source, test and native-capture review of the **unpublished 0.3 expansion**, not a release announcement. `Cargo.toml` identifies the working tree as the unreleased 0.3.0 candidate. The published Windows launcher product is **0.2.0**; its receipts in `STATUS.md` and `.blue-check/ui-polish/publication.json` certify that earlier release only. They do not certify these new systems, screenshots, performance or installer bytes.

This matrix follows the complete expansion checklist supplied by the user; emojis did not change the required scope. The original request is an original BlueEngine city builder named **BlueCity**, with classic SimCity and Cities: Skylines concepts, infrastructure investment and growing communities. This document tracks that behavior rather than claiming an exact reproduction of either commercial game.

Status key: **Tested** means the named behavior passed the recorded checks; **Source** means code was inspected without a dedicated behavior proof for the complete claim; **Review** identifies a presentation or player-experience limit beyond the named evidence; **Partial** identifies a concrete remaining gap; **Release** means a delivery gate remains open.
