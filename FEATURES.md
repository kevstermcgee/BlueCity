# BlueCity 0.3.0 feature traceability

Audit date: **2026-10-23**. The native 0.3.0 expansion is published from source [`cc76ba845d3c8f215ded8afa9b5029debf2e3735`](https://github.com/kevstermcgee/BlueCity/tree/cc76ba845d3c8f215ded8afa9b5029debf2e3735), with a [verified immutable Windows release](https://github.com/kevstermcgee/BlueEngineGames/releases/tag/bluecity-v0.3.0). [STATUS.md](STATUS.md) records installer hashes, launcher deployment and engine-review links. Earlier 0.2 receipts certify that historical release only.

The complete user checklist is implemented at the declared model scope; emojis did not change the requirements. BlueCity uses occupied lots/households, bounded trip and vehicle samples, grid infrastructure and neighboring trade contracts. It is an original city builder inspired by classic SimCity and Cities: Skylines, with no promise of exact commercial-game parity. Individual rows distinguish proof from broader presentation or play-review limits.

Status key: **Tested** identifies observed behavior checks; **Source** identifies inspected code without a dedicated proof for the complete claim; **Review** identifies presentation, balance or player-experience limits; **Partial** identifies a concrete gap; **Release** identifies delivery/feedback verification still tracked in STATUS. A catalog count or test file alone is not passing evidence.

The [published Windows workflow](https://github.com/kevstermcgee/BlueCity/actions/runs/39984257601) passed **158 Rust tests**, formatting/strict Clippy/content/audio, both 100-year runs, isolated package smoke, icon/resources, clean centered text-only studio startup, fullscreen controls and real installer install/reinstall-upgrade/uninstall. Final Linux checks passed the same 158 tests, strict all-target Clippy and stable-source isolated shipping smoke. Independent checks confirm published installer bytes match the tested package; the trusted Games mirror preserves the existing bundled latest release.

The released Windows 128²/15,009-building/360-day report records **2.057 ms mean / 3.298 ms p99 / 3.932 ms maximum**, with raw `target_met:true`, exact hash `e29c094ebf193923` and a 3,688,655-byte save. Release acceptance explicitly uses mean and p99 below 4 ms; raw maxima and the independent strict flag are retained. The local N97 maximum is 4.092 ms, an earlier Windows maximum is 4.649 ms, and longer century tests have larger outliers. No universal timing guarantee or unsupported explanation of spikes is claimed. [STATUS.md](STATUS.md) preserves workload, setup, host and earlier-failure details.

Native review proves upright projection and off-center Clock Tower selection (logical 496,333 → block 77,69), readable translucent controls and 150% Settings text, nonoverlapping seven-style/three-climate generation controls, a typed/saved Delta/Alpine seed 12345, and an actual automatic clean milestone postcard. The seven-image guide distinguishes starter, real automated growth and constructed showcases. Captures use software rendering/synthetic input; physical devices and audible output are unverified.

The maintenance-aware paid-rules bot completes 100 years from an empty River map, peaks at 70,377 residents and ends at 6,538 with $9,315,146, zero financial defaults/bankruptcy months/rescues and an exact 2,488,187-byte save. The dense century ends inhabited and solvent with an exact save. Linux and Windows preserve the same century results. These establish stability/balance observations, not optimal planning or a human fun rating.
